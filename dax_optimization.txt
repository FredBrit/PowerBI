### Основные сценарии оптимизации DAX

Сценарий 1. Итераторы против агрегаторов
Плохо (FE делает тяжёлую работу):

TotalAmount_Bad = 
SUMX(
    'Facts',
    'Facts'[Amount] * 1.15  -- Каждая строка обрабатывается в FE
)

Хорошо (SE делает всю работу):

TotalAmount_Good = 
SUM('Facts'[Amount]) * 1.15  -- SE считает сумму, FE только умножает скаляр  

Разница: В SUMX FE итерирует по каждой строке (миллионы операций). 
В SUM SE сканирует столбец целиком (одна операция), а FE умножает одно число.


Сценарий 2. Использование переменных (VAR) для избежания повторных вычислений  

Плохо (фильтр вычисляется дважды):

Sales_2022_Bad = 
CALCULATE(
    SUM('Facts'[Amount]),
    'Dates'[Year] = 2022
) + 
CALCULATE(
    SUM('Facts'[Amount]),
    'Dates'[Year] = 2021
)

Хорошо (фильтр вычисляется один раз):

Sales_2022_Good = 
VAR Sales_2022 = CALCULATE(SUM('Facts'[Amount]), 'Dates'[Year] = 2022)
VAR Sales_2021 = CALCULATE(SUM('Facts'[Amount]), 'Dates'[Year] = 2021)
RETURN
Sales_2022 + Sales_2021

Разница: Без VAR FE может пересчитывать фильтры несколько раз в зависимости от контекста.


Сценарий 3. FILTER против CALCULATE с прямым фильтром

Плохо (FE сканирует все строки):

Total_Bad = 
CALCULATE(
    SUM('Facts'[Amount]),
    FILTER('Dates', 'Dates'[Year] = 2022)  -- FILTER возвращает таблицу
)


Хорошо (SE применяет битмап):

Total_Good = 
CALCULATE(
    SUM('Facts'[Amount]),
    'Dates'[Year] = 2022  -- Прямой фильтр, SE использует битмап
)

Разница: FILTER заставляет FE материализовать таблицу в памяти. Прямой фильтр передаётся SE как битмап.



Сценарий 4. Использование TREATAS для кросс-фильтрации

Плохо (фильтр через RELATEDTABLE):

Sales_By_Category_Bad = 
CALCULATE(
    SUM('Facts'[Amount]),
    'Categories'[Category] = "Category_5"
)

Хорошо (TREATAS для явной фильтрации):

Sales_By_Category_Good = 
VAR SelectedCategory = "Category_5"
VAR CategoryIDs = 
    TREATAS(
        {SelectedCategory},
        'Categories'[Category]
    )
RETURN
CALCULATE(
    SUM('Facts'[Amount]),
    CategoryIDs
)

Разница: TREATAS позволяет SE использовать битмап напрямую, без дополнительных операций FE.
