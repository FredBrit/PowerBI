### VertiPaqAnalyzer

Общая схема сжатия
                          COLUMN
                            │
          ┌─────────────────┼──────────────────┐
          ↓                 ↓                  ↓
      Cardinality        Data Type          Encoding
          │                 │                  │
          └─────────────────┼──────────────────┘
                            ↓
                     COMPRESSION
                            │
               ┌────────────┼────────────┐
               ↓            ↓            ↓
             Data       Dictionary    Hier Size
               │            │            │
               └────────────┼────────────┘
                            ↓
                       Total Size


Table Size = Column sizes + User Hierarchies + Relationships
Это не размер файла .pbix.
В памяти модель может занимать больше, чем сохранённый файл.  


Cardinality
Это количество уникальных значений в колонке.
Можно уменьшить с помощью округления, уменьшения точности времени, группировки категорий, приведение непрерывного показателя к диапазонам, вместо DateTime делать отдельно Date,Day,Hour и тд  

Data
Размер сжатых данных сегментов колонки.
Сильно влияет:
-количество строк;
-cardinality;
-тип данных;
-encoding;
-распределение значений;
-эффективность compression.


Dictionary
Это размер структур dictionary для колонки. Особенно важен для Hash Encoding
Сильно влияет:
-много уникальных строк
-длинные строки
